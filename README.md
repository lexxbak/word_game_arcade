# Word Game Arcade

A simple C-based word game arcade featuring classic games like **Hangman** and **Wordle**. The project focuses on building interactive, terminal-based games with clean game logic, user input handling, word checking, and score tracking.

### Games Included

* **Hangman** – Guess the hidden word one letter at a time while trying to avoid running out of attempts.
* **Wordle** – Try to figure out the five-letter word within a limited number of guesses, with feedback after each attempt.

Built entirely in **C**, this project was created to practice programming fundamentals such as loops, functions, arrays, strings, conditionals, file handling, and input validation while making something fun and interactive.
